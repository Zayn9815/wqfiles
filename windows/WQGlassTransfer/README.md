# WQGlass Transfer for Windows

Fast, zero-headache wireless file transfer between **Windows 10/11** and **WQ Glass** on iPhone — no iTunes, no cables, no Bonjour drivers.

## Features
- **Automatic Wi-Fi Discovery:** Open **WQ Glass → Utility Hub → iPhone ↔ Windows Transfer** on your iPhone, and your iPhone automatically appears in the Windows app within 1 second.
- **4-Digit PIN Security:** Keeps your files private on shared Wi-Fi networks (remembers your last iPhone & PIN for 1-click reconnect).
- **Drag & Drop Files & Folders:** Drag any files or whole folders straight from Windows Explorer into the window to send to your iPhone.
- **Multi-GB Streaming Speed:** Streams directly to/from disk in 256 KB chunks with live `MB/s` speed, progress bar, and cancel button.
- **Full Remote File Controls:** Browse, search, download to PC, create folders, rename, and delete.

## How to Install on Windows
1. Open your GitHub repository → **Actions** → **Build Windows WQGlass Transfer** → download **WQGlassTransfer-Windows**.
2. Run **`WQGlassTransfer-Setup.exe`** to install normally (with Start Menu + Desktop shortcut), OR run portable **`WQGlassTransfer.exe`** directly without installing.
3. Connect both your iPhone and Windows PC to the same Wi-Fi, open **iPhone ↔ Windows Transfer** in WQ Glass, enter the 4-digit PIN, and transfer!
